Gmail in your browser

An extra check for suspicious Gmail messages.

Bye Bye Fishing is a free anti-phishing browser extension preview that checks visible senders, message text and links locally. Gmail’s own security protections remain essential.

Check a suspicious message in Gmail

  1. Read Gmail’s own warning first

    Do not dismiss a phishing warning simply because an extension shows no alert. Open the known website or app yourself when a message asks you to sign in or share information.

  2. Expand the sender details

    Check the full email address rather than the display name alone. A Gmail address is not automatically an official company address, and a visible From address can be forged.

  3. Check a Google security alert independently

    If a message claims to concern your Google Account, go directly to your Google Account security notifications. Do not use the email’s sign-in link to decide whether the alert is real.

  4. Report the message using Gmail

    In Gmail on a computer, open the message’s More menu next to Reply and choose Report phishing. See Google’s current reporting instructions for the latest interface.

What the extension adds

The preview compares visible sender and destination domains with a local brand catalog, looks for deceptive links and risky requests, and checks exact destinations against a packaged PhishTank snapshot. A warning explains the evidence and suggests a safer route. It does not upload the email or contact the destination.

The list of known malicious links expires after 30 days, so that part of the protection needs updated extension packages. A missing warning never establishes that a message is safe.

Gmail webmail and the Gmail app are different

The extension targets Gmail opened in a supported desktop browser. It does not scan the native Gmail mobile app, download attachments for inspection or authenticate a sender using Gmail’s server-side evidence. Android support is experimental; there is no iPhone package.

Installation and real Gmail compatibility still require testing before a broad release. For now, use the preview as an additional signal.
