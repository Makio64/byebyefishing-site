Support

Get help without sharing a private email.

Report a bug, request a supported webmail provider, or ask how a warning works through the public issue tracker. Never paste a real email, password, security code, or private account detail into a public report.

Open a support request Review the privacy policy

Before reporting a warning

Check the sender domain and destination independently. Redact names, addresses, order numbers, and message text before sharing a screenshot or example.

Installation help

The extension works in supported browser-based inboxes. It does not automatically scan the native Gmail, Outlook, Apple Mail, or Android mail apps. See the platform-specific installation guidance.

Security limitations

Bye Bye Fishing is an extra safety signal, not proof that a message is safe or malicious. When money, passwords, or security codes are involved, open the known app or site yourself.
