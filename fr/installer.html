Installer Bye Bye Fishing sur ordinateur.

Choisissez votre navigateur. Ces fichiers sont des préversions pour une installation manuelle ; les versions en boutique ne sont pas encore disponibles.

ZIP pour Chrome et EdgeZIP de test pour Firefox

Sans compte · Sans abonnement · L’interface de l’extension est actuellement en anglais

Empreintes SHA-256 des fichiers

ChromeOrdinateur
  1. Téléchargez le ZIP Chrome/Edge, puis décompressez-le.
  2. Ouvrez chrome://extensions et activez le mode développeur.
  3. Choisissez « Charger l’extension non empaquetée » et sélectionnez le dossier qui contient manifest.json.
  4. Acceptez les vérifications locales sur la page de confidentialité, puis ouvrez un webmail ciblé.
EdgeOrdinateur
  1. Téléchargez le même ZIP Chrome/Edge et décompressez-le.
  2. Ouvrez edge://extensions, activez le mode développeur et chargez le dossier décompressé.
  3. Activez la protection locale dans la page de démarrage, puis rechargez votre messagerie web.
FirefoxTest temporaire
  1. Téléchargez et décompressez le ZIP Firefox.
  2. Ouvrez about:debugging#/runtime/this-firefox.
  3. Choisissez « Charger un module complémentaire temporaire » et sélectionnez le fichier manifest.json.
  4. Activez les vérifications locales. Cette installation temporaire disparaît au redémarrage de Firefox.

Ce qui est disponible aujourd’hui

Les navigateurs de bureau Chrome, Edge et Firefox constituent les premières cibles. La compatibilité réelle avec chaque messagerie et navigateur reste à valider. Firefox Android est expérimental ; le ZIP ne s’installe pas comme une application Android. Aucun paquet Safari, iPhone ou iPad n’est disponible.

Après l’installation

Ouvrez le menu de l’extension pour vérifier que la protection locale est activée. Une page de webmail déjà ouverte peut nécessiter un rechargement. Le menu indique aussi la date de la liste de liens de phishing connus ; elle expire après 30 jours.

L’absence d’alerte ne garantit pas qu’un message est sûr. Les pièces jointes, les images et les QR codes ne sont pas analysés.

Besoin d’aide ?

Consultez le support en anglais ou le guide pour reconnaître un mail de phishing. Pour retirer l’extension, utilisez la page de gestion des extensions de votre navigateur.
