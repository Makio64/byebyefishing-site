Chrome Desktop
  1. Download the Chrome/Edge ZIP package.
  2. Keep the extracted folder on your computer so the local installation can load its files.
  3. For local testing, unzip it, open chrome://extensions, enable Developer mode, and choose Load unpacked.
  4. Enable local protection on the first-run privacy page, then open a targeted webmail page such as Gmail or Outlook.
Download Chrome/Edge ZIP
Edge Desktop
  1. Use the same Chrome/Edge package.
  2. Unzip the package and keep the extracted folder on your computer.
  3. For local testing, unzip it, open edge://extensions, enable Developer mode, and choose Load unpacked.
  4. Enable local protection on the first-run privacy page, then open your webmail in Edge.
Download Chrome/Edge ZIP
Firefox Desktop
  1. Download the Firefox package.
  2. Unzip the package. This temporary installation is removed when Firefox restarts.
  3. For temporary testing, open about:debugging#/runtime/this-firefox.
  4. Choose Load Temporary Add-on and select manifest.json from the unzipped package.
Download Firefox testing ZIP
Firefox Android Phones
  1. Install Firefox for Android.
  2. Use the Mozilla Add-ons listing once approved.
  3. The downloadable Firefox ZIP is for source review and developer testing, not normal installation on Android.
  4. Open mail.google.com, Outlook webmail, or another supported webmail site in Firefox.
  5. Remember that the native Gmail and Outlook apps are separate apps and are not scanned automatically.

Safari Deferred
  1. Safari is outside the initial release scope; no Mac, iPhone or iPad package is available.
  2. Use a desktop Chrome, Edge or Firefox preview for testing instead. Native Apple Mail is not scanned.
Developers Source build
  1. Public source publication is pending the license decision. Developer ZIPs are available above.
  2. Run npm test, then npm run icons and npm run package.
  3. Load the unpacked extension in Chrome, Edge, or Firefox.
  4. Review the plain-text rules before sharing with family or friends.

After downloading: enable, check, update.

Enable local checks

Review the first-run privacy page and enable protection. Reload an already-open webmail tab after installation.

Check the popup

The toolbar menu shows the local-protection status and the known-link list date. An expired list needs an updated extension package.

Get help if needed

Read the installation FAQ or ask for support with a fictional example. Do not share private email.

The preview can miss phishing and produce false alarms. It does not scan attachments, image-only text, QR codes or native Gmail, Outlook and Apple Mail apps. No warning means no guarantee.
