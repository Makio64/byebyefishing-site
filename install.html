Install

Use Bye Bye Fishing where webmail lives.

The extension protects supported webmail pages in browsers. It does not automatically scan native Gmail, Outlook, Apple Mail, or Android mail apps.

Browser-specific setup

Pick the browser you use for webmail.

If we recognize your browser, the matching install path opens below. The other browser instructions stay available without taking over the page.

See install steps Firefox testing ZIP
Chrome Desktop
  1. Download the Chrome/Edge ZIP package.
  2. When the store listing is live, install from the Chrome Web Store.
  3. For local testing, unzip it, open chrome://extensions, enable Developer mode, and choose Load unpacked.
  4. Open Gmail, Outlook, Yahoo, iCloud Mail, Proton Mail, or another supported webmail page.
Edge Desktop
  1. Use the same Chrome/Edge package.
  2. When published, install from Microsoft Edge Add-ons or Chrome Web Store if allowed.
  3. For local testing, unzip it, open edge://extensions, enable Developer mode, and choose Load unpacked.
  4. Open a supported webmail site and read a message.
Firefox Desktop
  1. Download the Firefox package.
  2. When the listing is live, install from Mozilla Add-ons.
  3. For temporary testing, open about:debugging#/runtime/this-firefox.
  4. Choose Load Temporary Add-on and select manifest.json from the unzipped package.
Firefox Android Phones
  1. Install Firefox for Android.
  2. Use the Mozilla Add-ons listing once approved.
  3. The downloadable Firefox ZIP is for source review and developer testing, not normal installation on Android.
  4. Open mail.google.com, Outlook webmail, or another supported webmail site in Firefox.
  5. Remember that the native Gmail and Outlook apps are separate apps and are not scanned automatically.
Safari Mac, iPhone, iPad
  1. Safari support ships as an App Store app containing the Safari Web Extension.
  2. Install the app when the App Store release is ready.
  3. Enable the extension in Safari settings.
  4. Use Safari webmail pages. Native Apple Mail is not automatically protected.
Developers Source build
  1. Clone the extension source.
  2. Run npm test, then npm run icons and npm run package.
  3. Load the unpacked extension in Chrome, Edge, or Firefox.
  4. Review the plain-text rules before sharing with family or friends.

Supported webmail

Built for everyday inboxes.

Bye Bye Fishing currently runs on Gmail, Outlook, Yahoo, AOL, iCloud Mail, Proton Mail, Tuta, Zoho, Fastmail, Orange, SFR, Free, La Poste, Bouygues, Mailo, GMX, Web.de, T-Online, Freenet, Mailbox.org, Posteo, Seznam, WP, Onet, O2, Interia, Libero, and Virgilio.
